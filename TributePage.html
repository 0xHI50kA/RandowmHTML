Linus Torvalds

Founder of the Linux kernel

Biography

Linus Benedict Torvalds (born 28 December 1969) is a Finnish and American software engineer
who is the creator and lead developer of the Linux kernel since 1991.
He also created the distributed version control system Git.

Achievements

  • Created the Linux kernel
  • Created Git
  • Received the 2012 Millennium Technology Prize
  • Received the 2014 IEEE Computer Society Computer Pioneer Award
  • Received the 2018 IEEE Masaru Ibuka Consumer Electronics Award
